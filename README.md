# homebrew-tap
Homebrew tap for ReplyPen tools.

```bash
brew install --cask replypen/tap/rp
```

`rp` is the ReplyPen CLI ([replypen/replypen-cli](https://github.com/replypen/replypen-cli)); the cask also links
`rc`, its pre-rename name. `Casks/rp.rb` is generated by GoReleaser on every release.
`cask_renames.json` (`{"rc":"rp"}`) migrates an installed `rc` cask on `brew upgrade`;
`tap_migrations.json` is the older formula→cask migration.
